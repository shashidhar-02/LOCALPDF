# Support & Community Resources

Thank you for using **LocalPDF**! Here are the best ways to get help, report issues, and connect with the community.

## Getting Help

- **Documentation & User Guides**: Explore step-by-step guides at [`/guides`](https://localpdf.dev/guides) and tool architecture details at [`/architecture`](https://localpdf.dev/architecture).
- **GitHub Discussions**: Have a general question, feature idea, or want to discuss client-side PDF technologies? Join our [GitHub Discussions](https://github.com/shashidhar-02/LOCALPDF/discussions).
- **GitHub Issues**: If you found a bug or technical issue, please [open an issue](https://github.com/shashidhar-02/LOCALPDF/issues/new/choose) using our structured templates.

## Core Commitments

- **Privacy First**: Remember that LocalPDF is 100% browser-only. Never share sensitive or proprietary PDF files when reporting a bug. Reproduce issues using sample or redacted files whenever possible.
- **Security Inquiries**: For security vulnerabilities, do not use public issues. Follow our [Security Policy](SECURITY.md) and report directly to `security@localpdf.dev`.
